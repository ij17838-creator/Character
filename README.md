# 제스처 드로잉 연습 (Gesture Drawing Trainer)

Mixamo 리깅 캐릭터(`character_2048.glb` 또는 `model.glb`)에 랜덤 포즈를 주고, 위에 직접 골조를 그린 뒤 정답 뼈대와 비교하는 웹 앱입니다.

## 실행

GLB는 `file://`로 열면 브라우저가 읽지 못하므로 로컬 서버로 실행하세요.

```bash
npx http-server .        # 또는: python3 -m http.server
# → http://localhost:8080 (python은 :8000)
```

모델은 `character_2048.glb`를 먼저 불러오고, 없으면 `model.glb`를 찾습니다. 다른 Mixamo GLB는 설정(⚙️)의 "다른 GLB 모델 열기"로 열거나 화면에 드래그 앤 드롭하면 됩니다.

## 기능

- **새 랜덤 포즈**: 척추·목·머리·쇄골·상완·전완·손목·대퇴·하퇴·발목을 인체 가동 범위 안에서 무작위로 회전합니다. 회전은 캐릭터 몸 기준 축(좌우/상하/전후)으로 계산한 뒤 각 본의 로컬 회전으로 변환하므로 본 축 방향과 상관없이 동작합니다. 발은 바닥에 맞춰집니다.
- **카메라 고정**: 켜면 드로잉, 끄면 OrbitControls로 회전합니다. 고정 상태에서도 Space를 누르고 있으면 잠시 회전할 수 있습니다.
- **드로잉**: Pointer Events(마우스, 터치, 펜 필압), 중점 2차 곡선 보간, 손떨림 보정, 펜/지우개, 색상, 굵기, 되돌리기/다시 실행, 전체 지우기(되돌릴 수 있음).
- **정답 보기**: 핵심 관절을 `vector.project(camera)`로 2D에 투영해 형광색 마커와 골조 라인으로 그립니다(중심선 초록, 왼쪽 시안, 오른쪽 마젠타, 어깨/골반 기울기 점선, 머리 타원). 3D 모델은 반투명해집니다.
- **제스처 타이머**: 30초~5분. 시간이 끝나면 정답을 자동으로 보여줍니다.

단축키: `N` 새 포즈 · `A` 정답 · `L` 카메라 고정 · `P` 펜 · `E` 지우개 · `[` `]` 굵기 · `Ctrl+Z` / `Ctrl+Shift+Z`
